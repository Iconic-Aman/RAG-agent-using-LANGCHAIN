# 🤖 Building a RAG Agent with LangChain + Streamlit

This project showcases a **Retrieval-Augmented Generation (RAG) Agent** built using [LangChain](https://www.langchain.com/) and deployed with a [Streamlit](https://streamlit.io/) interface. The agent can answer user queries by retrieving relevant information from local documents and generating responses using a language model.

---

## 🌟 Features

- 📄 Document ingestion (PDFs, TXT files)
- 🧠 RAG pipeline using LangChain
- 🔍 Retrieval from a vector store (FAISS/Chroma)
- 🤖 Language model-based response generation (OpenAI(Openrouter), Ollama)
- 🌐 Interactive Streamlit interface
- ⚡ Supports both local models and API-based LLMs

---

### Model that i have used in this project
- mistralai/mistral-7b-instruct: (Openrouter(cloud based))
- llama2-uncensored: Ollama(host locally)
